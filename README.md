# DevOps Development – Group-5

## Introduction

DevOps is a software development methodology that combines Development and
Operations to improve collaboration, automation, software quality and
deployment speed.

This repository contains the complete learning material, assignments,
weekly tasks, cheat sheets, reference resources and practical work related
to Development in DevOps.

## Objective

The main objectives of this repository are:

- Understand the role of Development in DevOps.
- Learn Git and GitHub.
- Understand branching and Pull Requests.
- Understand Continuous Integration and Continuous Delivery.
- Learn automated testing.
- Understand Docker and containerization.
- Practice DevOps development workflows.
- Learn basic deployment concepts.

## Development in DevOps

Development is one of the most important parts of the DevOps lifecycle.

Developers are responsible for:

1. Writing application code.
2. Maintaining source code.
3. Using version control.
4. Creating feature branches.
5. Testing applications.
6. Performing code reviews.
7. Fixing bugs.
8. Working with CI/CD pipelines.
9. Preparing applications for deployment.
10. Monitoring and improving applications.

## DevOps Lifecycle

Plan → Code → Build → Test → Release → Deploy → Operate → Monitor
